Название проекта
Bash‑скрипт для автоматизации файловых операций

Описание
Проект представляет собой Bash‑скрипт task.sh, созданный в рамках практического задания. Скрипт выполняет последовательность файловых операций (создание каталогов и файлов, копирование, перемещение, поиск и т. д.) с использованием стандартных команд Linux.

После запуска скрипт:

создаёт структуру каталогов и файлы;

выполняет манипуляции с файлами и правами доступа;

формирует отчёты в текстовых файлах;

выводит итоговую информацию в консоль;

удаляет все созданные данные, не оставляя следов после выполнения.

Цель задания
Отработать навыки работы с основными командами Bash:
cat, cd, chmod, cp, echo, find, grep, ls, mkdir, mv, rm, touch.

Примечания
Скрипт не оставляет следов после выполнения (все временные файлы и каталоги удаляются).

Все пути — относительные, поэтому скрипт можно запускать из любой директории.

Права доступа 764 соответствуют: владелец — rwx, группа — rw-, остальные — r--.

Ожидаемый вывод
При корректном выполнении скрипт выведет в консоль следующий текст:

./dir2/list.txt
./dir3/dir4/list.txt
./dir1/summary.txt
empty
hello.sh
list.txt
Всем студентам, привет!
